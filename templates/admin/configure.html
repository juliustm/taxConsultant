When no QR code can be decoded, the verification code and time the model reads off the paper are turned back into a portal address and put to TRA. It is the single most valuable step in the photo pipeline when it works — it replaces a transcription with TRA's own figures.

Turn it off if your devices photograph a lot of documents that are not EFD receipts — mobile-money messages, delivery notes, handwritten chits. Those carry a plausible run of digits too, so an address gets built that the portal will never confirm, and the submission spends its whole retry schedule finding that out. With this off, what the model read is stored directly and stays editable.

Either way, any single submission can be settled by hand from its own page.
